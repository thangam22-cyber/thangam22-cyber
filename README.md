### 🦠 ZeroWare — AI-Powered Malware Intelligence System
<table width="100%">
<tr>
<td align="left" valign="top">

**AI-powered malware detection and analysis platform that goes beyond "safe or malicious" to explain *why* a file is suspicious, what it resembles, and what it might do.**

ZeroWare analyzes PE structure, entropy, imports, APIs, sections, and metadata using ML models. Its standout feature is **ZeroDNA** — an AI-generated malware fingerprint that identifies similarities between unknown and known malware even when the hash changes. **ZeroReason** (Explainable AI) tells you *why* the model flagged it. It also predicts possible malicious behaviors without executing the file.

**Unique Features:**
`ZeroDNA` `ZeroReason XAI` `Zero-Day Risk` `Trust Engine` `Behavior Prediction` `Mutation Detection` `Similarity Engine` `AI Report Generator`

**Stack:** `Python` `Scikit-learn` `PEFile` `Flask` `Plotly` `SQLite`

### 🖥️ EndSight-OS — AI-Powered Endpoint Detection & Response (EDR) Platform
<table width="100%">
<tr>
<td align="left" valign="top">

**Enterprise-grade EDR platform inspired by Microsoft Defender, CrowdStrike Falcon, and Wazuh — built to monitor endpoints, detect threats with AI, and enable SOC-level investigation.**

EndSight-OS deploys a lightweight agent (OSQuery + Custom Scripts) on endpoints to gather live process, network, registry, USB, login, and file change data. An AI Threat & Risk Engine scores threats (0–100) using behavioral models mapped to **MITRE ATT&CK** and Sigma Rules.
